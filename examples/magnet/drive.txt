# Controlled hall-sensor events, which is the only way to test this without a
# magnet and a hand. The simulator's own device controls stand in for both.
wait-for No magnet
expect top edge
clean
shot magnet-sweeping-top
device cover closed
wait-for Magnet found
# Found, the line gives the answer instead of the instruction to sweep.
expect Found on the top edge.
expect 1 change so far.
expect-missing Hold a magnet
clean
shot magnet-found
device cover open
wait-for No magnet
expect 2 changes so far
tap Sweep the right edge
wait-for right edge
device cover closed
wait-for Magnet found
device cover open
wait-for No magnet
# The line counts the edge it names, as "Changes here" does: two here, not
# the four of the whole sweep.
expect 2 changes so far
expect-missing 4 changes so far
clean
shot magnet-swept-right
# A cleared count keeps the edge that was found, so the line does not go
# back to saying nothing has answered.
tap Reset the count
wait-for 0 changes so far
expect-missing Nothing has answered yet
wait 600
