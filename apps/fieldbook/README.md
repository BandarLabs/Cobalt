# Fieldbook

An unofficial eBird field companion for Kobo. It uses a manually selected,
offline field pack and keeps sightings locally by species code; no GPS is
requested or inferred.

![Fieldbook log screen](screenshots/log.png)

The MVP supplies an offline species picker with common, scientific and
four-letter names, a large TALLY control, life-list flags and local storage.
`kobo fieldbook export` is documented for eBird Record Format CSV. Checklist
submission is deliberately unavailable because Cornell Lab provides no public
write API. eBird and the Cornell Lab of Ornithology are credited trademarks.
