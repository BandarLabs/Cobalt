# Original sample

`a-small-garden.cbz` contains four original Cobalt pages. Rebuild it with
`scripts/quality/make-panels-sample.py` from the repository root. The page geometry,
captions and ComicInfo record were written for this project. Rendering uses the
existing Atkinson Hyperlegible font in the repository; its license stays with
the font. No third-party comic, artwork, source implementation or project name
is included. This sample and its generator use the repository license.
