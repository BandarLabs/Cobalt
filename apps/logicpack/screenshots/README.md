# Logic Pack screenshots

Simulator captures on Clara BW at the default text size, taken with
`kobo drive --ideal`:

- `collection.png`: the four games, with how many of each are solved.
- `collection-slither.png`: the Slitherlink list at one grade, a page at a time.
- `slitherlink.png` and `excluded-edge.png`: lines drawn, then gaps marked in
  Cross mode.
- `hashi.png` and `double-bridge.png`: single and double bridges, then the
  solved board offering the next puzzle.
- `kakuro.png` and `entry.png`: digits entered, and the chooser with both sums.
- `logicpack-mines.png`: a field opened with a safe patch, untouched squares
  shaded and one flag.
- `completed.png`: a cleared field with every mine flagged.
- `restart.png`: confirmation before clearing one puzzle.
- `save-failed.png`: retained moves after an injected full-store failure.

No network effects occur.
