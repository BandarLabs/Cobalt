# Nonograms

Solve a bundled, line-solvable grid with touch-first fill / X / blank entry. Each tap changes only its cell; opening and the completion reveal are full-panel repaints. The 9×9 bundled puzzle is the size gate used for the Clara BW.

The line-clue approach is independently implemented. Tatham's Puzzle Collection Pattern solver is an MIT-licensed reference, not linked or used at runtime. `Picross` is Nintendo's trademark and is not used by this app.

Photo puzzles and the port 9338 transfer protocol are deferred: this MVP is bundled play only, so it requires no capabilities.
