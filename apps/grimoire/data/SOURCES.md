# Corpus source ledger

`corpus.tsv` is generated by `tools/build_corpus.py` from the English JSON
snapshots under `source/`. The snapshots were obtained from
[`5e-bits/5e-database`](https://github.com/5e-bits/5e-database), whose
packaging is MIT licensed; the database records are SRD material.

Included sources:

| edition | records |
| --- | ---: |
| 2014 | spells, monsters, conditions, rules, rule sections, magic items |
| 2024 | monsters, conditions, magic items |

The source repository currently contains no English 2024 spell, rules, or rule
section files. A release claiming full 2024 parity is blocked pending a
reviewable CC-BY source snapshot for those records. The app retains the 2024
edition selector because all included 2024 records are rendered from their own
source data, never copied from the 2014 edition.

No artwork is shipped. No OGL-only third-party document is a corpus input.
