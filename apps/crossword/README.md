# Crossword

This touch-first game includes a bundled 5×5 word-square crossword, direction switching on a second tap, Across and Down clue lists, platform-keyboard letter entry, autosaved progress, and defensive `.puz` header validation. A letter redraws the grid only after that one input. The starter grid is sized for the Clara BW; 21×21 Sunday puzzles are intentionally gated until a larger-panel or scrolling layout is implemented.

`.puz` is an open file format. `.ipuz` import, the port 9337 transfer channel, rebus entry, and Crosshare fetching are not part of this compact bundled edition. Crosshare is AGPL-3.0 service software; commercial and NYT puzzles are never fetched.
