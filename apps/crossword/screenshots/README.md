# Crossword captures

Actual SDK app output from the Clara BW 391 simulator, extra-large interface
text. `crossword-play.png` shows a numbered blocked grid; `crossword-entry.png`
keeps the clue with entry; `completed.png` shows the fully solved puzzle.
`save-recovery.png` shows the storage-full recovery route. Capture metadata and
layout evidence are under `docs/quality/evidence/crossword/`. These are simulator
captures, not a claim of completed physical-reader acceptance.
