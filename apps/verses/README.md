# Verses

One deterministic public-domain poem each day, typeset as a reading page.

![Verses daily poem](screenshots/today.png)

The vendored MVP corpus includes provenance for every entry: author, first
publication year and source. Curation favours breadth of era, voice and length;
translations are accepted only when the translation itself is public domain.
Project Gutenberg source headers are not redistributed; source provenance is.
PoetryDB is planned as an optional bonus source, not a dependency for reading.
Sleep-screen integration is represented by an opt-in persisted setting pending
the runtime sleep-screen API.
