FAQ

Cobalt as an app platform.

Cobalt gives Kobo app developers one runtime and SDK for UI, lifecycle, rendering, device services, testing and distribution.

How is Cobalt different from NickelMenu?

NickelMenu adds custom actions to Kobo's stock interface. Cobalt uses one NickelMenu action to start the platform.

Cobalt then manages the launcher and every app session. Its runtime provides the UI toolkit, app lifecycle, framebuffer rendering, partial e-ink refreshes, touch input, storage, networking and device services.

How is Cobalt different from KOReader or Plato?

KOReader and Plato are standalone reading applications. They carry the UI and device integration needed by their application.

Cobalt is infrastructure for building many apps. Developers write app logic against the Cobalt SDK, while the runtime handles the shared platform work.

What does Cobalt provide to an app?

The SDK provides screens, controls, lifecycle events, background work, private storage and device service requests. The runtime handles layout, framebuffer drawing, refresh planning, touch input and communication with the device.

Cobalt implements this shared layer once so app developers do not need to build a UI toolkit and hardware stack for every new idea.

How are apps isolated?

Cobalt starts each app as a separate unprivileged process. Apps declare the services they need, such as network, storage, audio, Bluetooth or frontlight access, and the runtime checks each request.

Store also verifies signed catalogs, packages, manifests and binaries before launch.

How do developers build and test an app?

kobo new creates an app project. kobo dev runs it in the browser simulator, with the same screen model used on the reader.

When the app is ready, the tooling builds and packages it for supported Kobo hardware. The app does not need its own framebuffer, touch or service implementation.

What does the Store add?

The first Cobalt installation uses USB. After that, Store can install, update and remove signed apps over Wi-Fi. App releases are separate from Cobalt platform releases, so publishing one app does not require reinstalling the platform.

Hardware support is exact. Check the device support matrix before installing Cobalt.
