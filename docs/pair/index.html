Link your Kobo

Pair this browser once, then install signed apps from any Cobalt app page.

Confirm your Kobo

On the Kobo, open App Store and choose Link a browser. Enter the pairing code and verification key it shows, or scan its QR code with your phone to fill them in.

Choose an app

No account is required. Install requests are encrypted in this browser and can only be opened by the linked Kobo.
