Install from this page

This writes Cobalt and NickelMenu to a Kobo connected by USB, from the browser. There is no terminal step, and nothing is uploaded: the reader is written to directly by this page.

This browser cannot write to the reader.

  1. Connect the reader

    Plug the Kobo in and tap Connect on its screen. It appears as a drive called KOBOeReader. Then choose that drive here.

    Your browser will ask permission to edit files on the drive. Only .kobo and .adds are written.

  2. Fetch the release

    Downloads the current release and checks it against the digest published beside it. A file that does not match is discarded rather than written.

  3. Write it to the reader

    Writes the release into the slot the firmware reads at startup, and adds a Cobalt entry to NickelMenu. Entries you or other mods have added are left alone.

  4. Eject and restart

    Eject the drive from your computer, unplug the cable, and hold the power button until the reader restarts. It shows an update screen while the firmware unpacks Cobalt, then returns to the home screen.

    Leave the home screen alone for about a minute afterwards. NickelMenu uses that time as a failsafe and switches itself off if a start is interrupted. Then open the menu in the bottom-right corner and choose Cobalt.
