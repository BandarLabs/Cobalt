Install Cobalt directly from your browser

Writes Cobalt and NickelMenu to a Kobo plugged into this computer. No terminal, nothing uploaded.

This browser cannot install Cobalt.

Other ways to install

Terminal One command

Plug the Kobo into a computer and tap Connect on the reader's screen. Then in Terminal:

curl -fsSL https://bandarlabs.github.io/Cobalt/install.sh | sh

Installs the kobo command, then writes Cobalt and NickelMenu to the reader, adds the menu entry and ejects the drive. Keeps what is already on the reader. It also turns on the reader's SSH server with a key only this computer holds, then saves the reader when it is back on Wi-Fi, so apps that take files from your computer work straight away.

From source Build it yourself

Needs Rust and an ARM C cross-compiler (the full walkthrough names the package). Builds the same thing the others download. Plug the Kobo in and tap Connect on its screen first.

git clone https://github.com/BandarLabs/Cobalt.git
cd Cobalt
rustup target add armv7-unknown-linux-musleabihf
cargo run -p kobo-cli -- setup --source

Any computer Copy one file

No terminal, and any browser. It is the same file the browser install below writes.

  1. Download the Cobalt file
  2. Plug the Kobo in. It asks on its own screen whether to connect: tap Connect. It shows up as a drive called KOBOeReader.
  3. Copy the file into the .kobo folder, named exactly KoboRoot.tgz. That folder is hidden: on a Mac press ⌘⇧. in Finder, on Windows turn on Hidden items in the View tab.
  4. Eject the drive, unplug, then hold the power button until the reader restarts.

      Eject and restart your Kobo
      
        
      Eject the drive before unplugging. A page cannot do this for you, and it is not a formality: your computer may still be holding part of the file in memory, and ejecting is what finishes writing it. Unplugging first can leave the reader with half an update.
      
        
        
      Then hold the power button until the reader restarts. It shows an update screen while the firmware unpacks Cobalt, and returns to the home screen.
      
        
      Leave the home screen alone for about a minute afterwards. NickelMenu uses that time as a failsafe and switches itself off if a start is interrupted. Then open the menu in the bottom-right corner and choose Cobalt.
      
        
      Some apps take photos, scores, notes or accounts from your computer. A page cannot give the reader a key for that, so those apps need the Terminal command under Other ways to install once, with the reader plugged in. It keeps everything already on the reader.
