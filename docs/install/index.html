Install from this page

This writes Cobalt and NickelMenu to a Kobo connected by USB, from the browser. There is no terminal step, and nothing is uploaded: the reader is written to directly by this page.

This browser cannot write to the reader.

Install by hand instead

Every browser can do this, and it is the same file the steps below would write. Nothing here needs a terminal.

  1. Download the Cobalt archive
  2. Plug the Kobo in and tap Connect. It appears as a drive called KOBOeReader.
  3. Copy the file into the .kobo folder on that drive, named exactly KoboRoot.tgz. The folder is hidden: on macOS press ⌘⇧. in Finder, on Windows turn on Hidden items in the View tab.
  4. Eject the drive, unplug the cable, and hold the power button until the reader restarts.

    Write it to the reader
    
        
    Writes the release into the slot the firmware reads at startup, and adds a Cobalt entry to NickelMenu. Entries you or other mods have added are left alone.
    
        
        
    
      
    
    
    5. 

    
  5. 
      
    
        
    Eject and restart
    
        
    Eject the drive from your computer, unplug the cable, and hold the power button until the reader restarts. It shows an update screen while the firmware unpacks Cobalt, then returns to the home screen.
    
        
    Leave the home screen alone for about a minute afterwards. NickelMenu uses that time as a failsafe and switches itself off if a start is interrupted. Then open the menu in the bottom-right corner and choose Cobalt.
    
      
    
    
    6. 
  


  

    Remove Cobalt from a reader
    

      
Takes off the Cobalt programs and its entry in the reader's menu. It keeps everything you put there: your books, settings, credentials, and the applications with their data. Installing again later picks them up where they are.

      
NickelMenu itself is left alone — other mods use it — and so is any menu entry that is not Cobalt's.
