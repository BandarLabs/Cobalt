# Quality evidence lives outside the tree

The simulator-run evidence for this pull request (screenshots, result JSON
and logs referenced from `docs/quality/tasks.json` evidence notes) is
attached as a release asset rather than committed:

https://github.com/mp663z/Cobalt/releases/download/pr-211-evidence/pr211-evidence.tar.gz

Paths referenced from the task board resolve inside that archive. Curated
screenshots the catalog and READMEs render remain in `apps/*/screenshots/`.
Committed evidence goes stale within two app releases and every clone,
CI checkout and release runner pays for it forever.
