# Needles prepared, sent, and offline-state evidence

The real CLI processed the previously recorded public-domain 1917 *Priscilla
War Work Book* material. `bundled-help.txt` records the local catalog guide. `prepare.txt` and `preview.txt` distinguish local,
reviewable output that was not sent. `sent.txt` identifies the simulator
transfer and says the result is available offline. The prepared and simulator
copies have the same SHA-256 recorded in `result.json`.

The running Needles app first showed the actionable no-pattern state, then
opened the CLI-written pattern and returned to its offline row counter.
`before-read.png`, `after-cli-open.png`, and `available-offline.png` were
pixel-inspected at 922x1246; text is legible and there is no overlap or clipping.

This proves one full companion workflow and advances CLI-27 and CLI-28. It does
not prove catalog-wide wording, a physical transfer, or physical offline use.
