# Catalog build paths

The catalog generator emits repository-relative manifest paths inside
`include_str!(concat!(env!("CARGO_MANIFEST_DIR"), "/../../", ...))`. Paths are
stripped from the repository root and emitted as escaped Rust string literals.
Generated source no longer contains the developer or CI checkout root.

Validation: the build script generated byte-identical source in two temporary
checkouts with different root names. Both included all 44 current app/example
manifests plus a path containing quotes and Unicode; compiling and running each
result resolved every include correctly. The catalog validity/uniqueness test,
format check and strict all-target Clippy pass with Rust 1.85.1.

This verifies stable generated source, not complete binary reproducibility:
compiler debug information and other build inputs have separate path behavior.
Runtime catalog content and UI are unchanged, so existing screenshots still apply.
