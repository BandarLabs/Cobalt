Tailscale

Put your Kobo on your Tailscale tailnet. Send books and articles to it from any network with kobo send and kobo clip, and reach your own servers from its apps. It runs while Cobalt is open, and can stay connected, act as an exit node and share your home network if you switch those on.

Before you install

  1. Set up the reader once over USB, if you have not already. Setup also closes password login to the reader, which Tailscale requires before it will start. kobo setup
  2. On the reader, open Tailscale and turn on the switch. The first time, the reader downloads Tailscale over Wi-Fi, about 37 MB, and checks it before running it.
  3. Scan the code on the reader with your phone, sign in to Tailscale and approve the reader. The screen then shows the reader's tailnet name and address.
  4. Save that address on this computer. After this, kobo send and kobo clip reach the reader from any network while Cobalt is open on it. kobo pair kobo --device 100.64.0.7

Commands need the kobo command on macOS, Linux or Windows WSL. This installs it ready-built, without touching the reader: curl -fsSL https://bandarlabs.github.io/Cobalt/install.sh | sh -s -- --no-setup

New to Cobalt? Install it from your browser.

Plug your Kobo into this computer and install Cobalt in about a minute. After that, apps install over Wi-Fi.

Works in Chrome, Edge and Opera. Check your Kobo is supported.

Install Cobalt

Already have Cobalt? Link your Kobo.

On your Kobo, open App Store and tap Link a browser in the top bar, then Link a browser again. Scan the QR code, or enter the pairing code and verification key it shows.

Install on your Kobo

Your Kobo checks the app's signature before installing it.

New in 0.1.0

First release. One switch, sign-in by scanning a code with your phone, and options to stay connected outside Cobalt, offer the reader as an exit node and share its network, each off until you turn it on.
