App setup

Before you install

  1. Set up the reader once over USB, if you have not already. Home Assistant must be reachable over HTTPS (Nabu Casa or a reverse proxy with a trusted certificate). Plain http:// addresses do not work. kobo setup
  2. Create a long-lived access token on your Home Assistant profile page.
  3. Connect Home Panel from your computer. It asks for the address and the token, checks them, and sets the panel up. Open Home Panel, or tap Check again. kobo connect homepanel
  4. For a private certificate authority, install its root on the reader. Pass the same file to kobo connect with --ca. kobo trust set homeassistant --from root-ca.pem

Commands need the kobo command on macOS, Linux or Windows WSL. This installs it ready-built, without touching the reader: curl -fsSL https://bandarlabs.github.io/Cobalt/install.sh | sh -s -- --no-setup

New to Cobalt?

Install Cobalt from your browser

Plug your Kobo into this computer and install Cobalt in about a minute. After that, apps install over Wi-Fi.

Works in Chrome, Edge and Opera. Check your Kobo is supported.

Already have Cobalt?

Link your Kobo to install

On your Kobo, open App Store, tap the globe in the top bar and choose Link browser. Scan the QR code, or enter the pairing code and verification key.

Install on your Kobo

Your Kobo checks the app's signature before installing it.
