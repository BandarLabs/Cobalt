Digest

Bring unread Miniflux articles to your Kobo and keep reading without Wi-Fi. Digest is an unofficial client and is not affiliated with or endorsed by the Miniflux project.

The network

Before you install

  1. Set up the reader once over USB, if you have not already. Miniflux must be reachable over HTTPS. kobo setup
  2. In Miniflux, create an API key (Settings, API Keys).
  3. Connect Digest from your computer. It asks for the server and the key, checks them, ties the key to your server, and fills in the address. Open Digest, or tap Check again. kobo connect rss-miniflux
  4. With the key in a file instead, the same setup is one command. kobo secret set miniflux --app rss-miniflux --server https://miniflux.example --from key.txt

Commands need the kobo command on macOS, Linux or Windows WSL. This installs it ready-built, without touching the reader: curl -fsSL https://bandarlabs.github.io/Cobalt/install.sh | sh -s -- --no-setup

New to Cobalt? Install it from your browser.

Plug your Kobo into this computer and install Cobalt in about a minute. After that, apps install over Wi-Fi.

Works in Chrome, Edge and Opera. Check your Kobo is supported.

Install Cobalt

Already have Cobalt? Link your Kobo.

On your Kobo, open App Store and tap Link a browser in the top bar, then Link a browser again. Scan the QR code, or enter the pairing code and verification key it shows.

Install on your Kobo

Your Kobo checks the app's signature before installing it.

New in 0.1.14

When a sync fails before any articles arrive, Digest no longer says you have no unread articles. Suggested feeds no longer repeats the connect screen's account message.
