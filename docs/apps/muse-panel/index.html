Muse Panel

Turn your Kobo into a Muse gadget: Muse puts a status line, a page or a question on the e-ink panel, and your taps go back to it.

New in 0.1.0

First release. Pair with a computer running the Muse bridge, read pages Muse sends, and answer its questions with a tap.

App setup

Before you install

  1. On a computer that is paired with Muse as a gadget, run the Muse bridge and note the address and pairing code it prints. kobo-bridge init
  2. Install the certificate authority the bridge printed, so the panel can verify it. kobo trust set muse-panel --from ca.pem --device <address>

New to Cobalt?

Install Cobalt from your browser

Plug your Kobo into this computer and install Cobalt in about a minute. After that, apps install over Wi-Fi.

Works in Chrome, Edge and Opera. Check your Kobo is supported.

Already have Cobalt?

Link your Kobo to install

On your Kobo, open App Store, tap the globe in the top bar and choose Link browser. Scan the QR code, or enter the pairing code and verification key.

Install on your Kobo

Your Kobo checks the app's signature before installing it.
