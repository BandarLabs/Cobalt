Readeck

Read and search your saved Readeck articles. Needs an account.

Install on your Kobo Source code on GitHub
Version
0.1.8
Needs
Cobalt 0.3.34 or newer
May use
The network, the front light

Before you install

  1. Set up the reader once over USB, if you have not already. Readeck must be reachable over HTTPS. kobo setup
  2. In Readeck, create an API token that can read and update bookmarks (Settings, API tokens).
  3. Connect Readeck from your computer. It asks for the server and the token, checks them, and saves both on the reader while Cobalt runs. Open Readeck, or tap Check again if it is already open. kobo connect readeck
  4. Articles you open are kept on the reader, so they read the same without Wi-Fi.

Commands need the kobo command on macOS, Linux or Windows WSL. This installs it ready-built, without touching the reader: curl -fsSL https://bandarlabs.github.io/Cobalt/install.sh | sh -s -- --no-setup

New to Cobalt? Install it from your browser.

Plug your Kobo into this computer and install Cobalt in about a minute. After that, apps install over Wi-Fi.

Works in Chrome, Edge and Opera. Check your Kobo is supported.

Install Cobalt

Already have Cobalt? Link your Kobo.

On your Kobo, open App Store and tap Link a browser in the top bar, then Link a browser again. Scan the QR code, or enter the pairing code and verification key it shows.

Install on your Kobo

Your Kobo checks the app's signature before installing it.

New in 0.1.8

Articles kept for offline reading now open without Wi-Fi, and refreshing keeps your list on screen. The inbox shows its page count, the reading controls have text size again, and an address typed without https:// is accepted.
