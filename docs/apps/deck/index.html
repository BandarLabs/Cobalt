Before you install

  1. Set up the reader once over USB, if you have not already. kobo setup
  2. In your project folder on the computer, lay out your first pads. Change them later with kobo deck set. kobo deck init --preset build
  3. Pair this computer with the reader. There is nothing to type on the reader. The first time, close Cobalt and open it again afterwards. kobo sidekick init
  4. Start the helper and leave it running, then open Deck on the reader. kobo sidekick run

Commands need the kobo command on macOS, Linux or Windows WSL. This installs it ready-built, without touching the reader: curl -fsSL https://bandarlabs.github.io/Cobalt/install.sh | sh -s -- --no-setup

New to Cobalt? Install it from your browser.

Plug your Kobo into this computer and install Cobalt in about a minute. After that, apps install over Wi-Fi.

Works in Chrome, Edge and Opera. Check your Kobo is supported.

Install Cobalt

Already have Cobalt? Link your Kobo.

On your Kobo, open App Store and tap Link a browser in the top bar, then Link a browser again. Scan the QR code, or enter the pairing code and verification key it shows.

Install on your Kobo

Your Kobo checks the app's signature before installing it.

New in 0.2.15

Pads sent from your computer while Deck shows the pairing steps now appear straight away, and a pad in the preview no longer offers to run on a computer that is not paired. Deck also keeps checking after a press your computer missed.
